# Ace Crawl Enhancer developer guide

Ace Crawl Enhancer provides metadata, canonicals, robots directives, sitemaps and structured data for WordPress. Start with the [project README](../../README.md) for features and installation, and the [WordPress readme](../../readme.txt) for requirements and optional services.

- [Hooks](Hooks.md) lists stable integration points and example callbacks.
- [Compatibility](Compatibility.md) records what to check before changing or installing the plugin.
- [Build and release](Build-and-release.md) explains how to reproduce the reviewed release ZIP.
- [Privacy and deployment](Privacy-and-deployment.md) covers optional providers and site-specific policies.

Open a public issue for a reproducible bug or feature request. See [CONTRIBUTING](../../CONTRIBUTING.md) and [SECURITY](../../SECURITY.md) before sharing code or vulnerability details.
