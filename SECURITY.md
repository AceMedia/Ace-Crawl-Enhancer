# Security policy

Please report a suspected vulnerability privately. Use GitHub's private vulnerability reporting form on this repository's **Security** tab if it is available, or email [shane@acemedia.ninja](mailto:shane@acemedia.ninja). Do not include exploit details, credentials or customer data in a public issue.

Include the affected plugin version, WordPress and PHP versions, relevant integrations, required privileges and a small reproduction using fictional content. Explain the impact and any proposed fix. Test only systems you own or have permission to assess.

The latest official release is the supported line for security fixes. Older releases have no backport commitment. WordPress and PHP minimum requirements are stated in each release's readme; those requirements are separate from a promise to support old plugin releases. No fixed response or patch deadline is offered.
