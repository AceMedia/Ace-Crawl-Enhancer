# Contributing

I maintain this plugin as part of the Ace Media suite. Bug reports, useful suggestions and documentation corrections are welcome through public GitHub issues. Please search existing issues first and keep each report focused on one problem.

Official code contributions are by invitation. Please discuss an idea in an issue before spending time on a patch; I may invite you to work on an agreed change. An issue or invitation does not guarantee that a change will be accepted. Ace Media retains responsibility for reviews, merges and official releases.

This contribution policy governs participation in this repository. It does not restrict the rights to use, study, modify or redistribute the software under its licence, including maintaining your own fork. See the repository's licence and third-party notices for the applicable terms.

## Reporting a problem

Include the plugin version, WordPress and PHP versions, relevant integrations, whether multisite is enabled, and a small reproduction using fictional content. Explain what you expected and what actually happened. Remove personal data, customer details, tokens, passwords, authentication QR codes and private URLs from screenshots and logs.

For vulnerabilities, follow SECURITY.md instead of posting technical details publicly.

## Invited changes

Keep changes focused and preserve existing settings, saved content, hooks and supported integrations. Include a regression test or a reproducible verification procedure for the behaviour being changed. State which WordPress, PHP, multisite and WooCommerce combinations you actually checked; do not claim support for combinations you have not tested.

Use British English for documentation and interface copy. Include any necessary migration notes, public hook documentation and third-party licence notices. Do not include client content, local agent instructions, credentials, private deployment details or unrelated changes.

Contributions must be compatible with the project's existing licence and retain attribution. Release permissions remain with the maintainers.
